# 学习：按计划完成一次

## 1. 开场（简短）

1. 从 `plan.md` 找到第一个未完成的学习次数（用户指定的除外）。
2. 告诉用户：本次目标、练习任务、对应资源章节、预计用时。
3. 如果 `weak-points.md` 中有与本次相关的待巩固薄弱点，提醒用户这次顺便留意。
4. 用 `date` 记下开始时间。

## 2. 学习中

用户以外部资源为主，AI 负责：

- **答疑**：用户随时提问。先确认对方卡在哪里，再解释；用例子，必要时给最小可运行示例。
- **讲解**：用户要求时讲解当前知识点，一次一个，讲完问一句确认是否懂了。
- **陪练**：用户做练习任务时，帮着看产出（代码、作品），指出问题但尽量不直接给完整答案，先给提示。
- 用户提问中暴露出的误解，记为候选薄弱点。

## 3. 结束

用户说"学完了"或练习完成后：

1. 用 `date` 记录结束时间，算出时长。
2. 请用户用一两句话说说这次学到了什么（不评分，只记录）。
3. 在 `plan.md` 将本次标记为完成，写上日期。
4. 追加 `log.md`：时长、完成内容、产出位置、提问摘要、候选薄弱点。
5. 默认进入考官模式的"课后考"（读 [exam.md](exam.md)）；用户说不考就跳过，下次开场时提醒补考。
6. 按记录规则更新 `INDEX.md` 并提交。

## 节奏调整信号

出现以下情况时，记在 `log.md`，并建议进入复盘：

- 实际用时比计划多出 50% 以上
- 练习任务明显太难或太简单
- 连续两次学习都有同类误解
