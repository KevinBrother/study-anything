# 资源筛选：5 个资源 + 7 天路径

## 1. 找候选

- 有联网搜索或网页抓取工具时，**必须**先搜索，只推荐确认存在的资源，并附上真实链接。
- 没有联网能力时，只推荐非常知名且确定存在的资源（官方文档、经典书籍），并明确告诉用户"链接未验证"。
- 官方文档优先；其次是高质量教程、课程、书；版本要与当前主流版本一致。

## 2. 选出 5 个

每个资源写明：

- **适合谁**、**难度**（入门/进阶/深入）
- **怎么用**：看哪几章/哪几节，配合计划第几次
- **可以跳过**：哪些部分与目标无关
- **链接**及是否已验证

参考 `profile.md` 的偏好（文档/视频/动手）调整比例。

## 3. 7 天路径

用这 5 个资源排一个 7 天路径，每天：资源 + 具体章节 + 当天练习 + 预计用时。路径要与 `plan.md` 的前几次学习对应，冲突时以 `plan.md` 为准，并在 `plan.md` 中为每次学习标注所用资源。

## 4. 持续维护

- 学习中发现某个资源不好用、过时或太难，在 `resources.md` 中标注原因并替换，记入 `changelog.md`。
- 用户自己找到的好资源也加进来，标注"用户推荐"。

写入 `resources.md` 后按记录规则提交。
